# Todo List — README

This project is a simple Todo List built entirely inside a **single HTML file**. All styling (CSS) and functionality (JavaScript) are embedded directly within the same file, making it easy to understand, edit, and share.

## Features

* Add new tasks quickly
* Mark tasks as completed
* Remove tasks individually
* Clean, minimal UI
* Uses Local Storage for storing tasks
* Beginner-friendly structure since everything lives in one file

## How It Works

* The HTML provides the structure of the page.
* The CSS is written inside `<style>` tags to handle layout and visual design.
* The JavaScript is included inside `<script>` tags and controls adding, checking, and deleting todos.

## How to Run

1. Download or copy the single HTML file.
2. Open it in any modern web browser.
3. The Todo List will work instantly — no setup required.

## File Overview

* **index.html** — The only file in the project. Contains the HTML markup, embedded CSS, and embedded JavaScript.
