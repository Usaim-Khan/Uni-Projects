# Uni Projects

A collection of projects built during my Computer Science degree at FAST NUCES, Karachi. Each project lives in its own folder with its own README covering the details — this file is just an index.

## Projects

| Project | Description | Language | Course |
|---|---|---|---|
| [Library Management System](./library-management-system) | Console-based library system with tiered memberships, book borrowing, and fine tracking | C | Programming Fundamentals |
| [GridNexus](./GridNexus) | OOP simulation of a decentralized smart power grid with energy-sharing between nodes | C++ | Object-Oriented Programming |

More projects will be added here as the degree progresses.

## Structure

```
Uni-Projects/
├── README.md                     ← you are here
├── library-management-system/
│   └── README.md
├── GridNexus/
│   └── README.md
└── <next-project>/
    └── README.md
```

Each project folder is self-contained — source code, any data/report files, and a README explaining what it does and how to run it.

## Adding a New Project

1. Create a new folder at the repo root, named after the project.
2. Add the project's code and a `README.md` inside it (what it does, how to build/run it, course it was for).
3. Add a row for it in the table above.
